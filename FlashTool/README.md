# EDwIC USB Flasher

Ця невеличка програма (скрипт) дозволяє користувачам прошивати ваш пристрій (firmware.bin та littlefs.bin) через USB в один клік.

## Як зібрати програму в `.exe` файл (для Windows)
Щоб ваші користувачі не встановлювали Python, ви можете зібрати цей скрипт у зручний `EDwIC_Flasher.exe`.

1. Переконайтеся, що на вашому комп'ютері встановлений Python (при установці обов'язково поставте галочку "Add Python to PATH").
2. Запустіть файл `build.bat` (просто подвійним кліком) для стандартної 64-бітної версії.
3. **Для 32-бітної Windows:** Якщо вам потрібна версія для старих систем, встановіть 32-бітний Python та запустіть `build_x86.bat`.
4. Дочекайтеся завершення. У папці `FlashTool` з'явиться нова папка `dist`.
5. У папці `dist` ви знайдете готовий файл `EDwIC_Flasher.exe` (або `EDwIC_Flasher_x86.exe`).

## Як користувачам прошивати пристрій
Коли ви хочете відправити оновлення користувачам, вам потрібно передати їм 3 файли в одній папці:
1. `EDwIC_Flasher.exe` (який ви щойно зібрали)
2. `firmware.bin` (ваш актуальний файл прошивки)
3. `littlefs.bin` (файл з файловою системою)

**Інструкція для користувача:**
1. Підключіть пристрій до комп'ютера по USB.
2. Запустіть `EDwIC_Flasher.exe`.
   - *Увага:* Оскільки програма не має дорогого цифрового підпису, Windows 11 може показати синє вікно "Windows захистив ваш ПК" (SmartScreen). Натисніть **"Детальніше" (More info)**, а потім кнопку **"Виконати в будь-якому разі" (Run anyway)**.
3. Програма автоматично знайде потрібний COM-порт. Якщо ні — натисніть кнопку "Визначити COM порт".
4. Якщо порт не з'явився, натисніть "Встановити драйвер (CH340)" та дочекайтеся встановлення.
5. Натисніть кнопку "Оновити прошивку" та дочекайтеся завершення (близько 1 хвилини).
6. Після успішного завершення пристрій автоматично перезавантажиться з новою прошивкою!

## Можливі помилки
Якщо після запуску `build.bat` віконце одразу закривається, переконайтеся, що Python встановлено правильно (відкрийте командний рядок CMD і введіть `python --version`, якщо буде помилка — потрібно перевстановити Python з галочкою "Add to PATH").
