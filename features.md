# EDwIC — Опис Можливостей та Функціоналу (v3.7.0)

EDwIC (ESP8266 Telegram Bot) — це потужна система моніторингу та автоматизації мікроклімату, розроблена для забезпечення максимального контролю через Telegram та сучасний веб-інтерфейс.

## 🌡️ Моніторинг та Сенсори
- **Підтримка датчиків:** Температура, вологість та атмосферний тиск (BME280, HTU21D, DS18B20).
- **Живий статус:** Дані оновлюються в реальному часі на OLED-дисплеї, в Telegram та у веб-дашборді.
- **Тенденції:** Візуальна індикація тренду зміни температури (📈 зростання, 📉 падіння, ↔️ стабільно).

## 🤖 Автоматизація та Режими Керування
1. **Ручний режим:** Керування через Telegram (inline кнопки) або веб-інтерфейс.
2. **Автоматика по датчику (Термостат):** Увімкнення/вимкнення реле залежно від цільової температури та гістерезису.
3. **Автоматика по часу (Циклічний таймер):** Робота за заданими інтервалами (наприклад, 10 хв увімкнено, 50 хв вимкнено).
4. **Профілі "День/Ніч":** Можливість задати різні параметри автоматики для денного та нічного часу. 
   - **NEW:** Похвилинне налаштування часу перемикання (наприклад, 07:30 - День, 22:45 - Ніч).
   - Автоматичне перемикання за точним часом (NTP).

## 📲 Інтеграція з Telegram
- **Повноцінний Дашборд:** Отримання статусу однією командою.
- **MiniApp:** Вбудований веб-додаток прямо в Telegram для візуального керування.
- **Сповіщення:**
    - Тривога при виході температури за межі.
    - Сповіщення про зміну статусу реле.
    - Звіт про запуск пристрою та стан живлення 220В.

## 🌐 Веб-інтерфейс (Panel)
- **Сучасний дизайн:** Glassmorphism інтерфейс з анімаціями та темною темою.
- **Динамічні графіки:** Візуалізація історії показників за сьогодні, вчора або довільний період.
- **Система відстеження змін:** Розумна індикація незбережених правок ("Dirty State") з блокуванням випадкової навігації.
- **Менеджер часових поясів:** Підтримка POSIX-рядків та вибір міст зі списку для автоматичного переходу на літній час.

## 💾 Логування та Пам'ять
- **Smart Logging:** Запис даних у форматі NDJSON із розбиттям по днях.
- **Оптимізація пам'яті:** Прямий стрімінг даних у сокет для стабільної роботи при малому об'ємі Heap.
- **Авто-ротація:** Система автоматично очищує старі логи при нестачі місця.

## ⚡ Системні можливості
- **Універсальна прошивка:** Один бінарний файл підтримує два типи OLED дисплеїв (0.66" та 0.96") з перемиканням у налаштуваннях.
- **OTA Оновлення:** Бездротове оновлення прошивки та веб-файлів напряму з GitHub.
- **NTP Синхронізація:** Підтримка POSIX-формату часу для точності в будь-якому регіоні.
