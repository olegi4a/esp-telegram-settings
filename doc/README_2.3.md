## 🚀 Встановлення прошивки

### **Крок 1: Підготовка**

1. Встановіть Arduino IDE 1.8.x або 2.x
2. Додайте ESP8266 до Board Manager:
   ```
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
3. Встановіть **ESP8266 by ESP8266 Community** версії 3.1.2
4. Встановіть бібліотеки (див. вище)

### **Крок 2: Завантаження**

1. Відкрийте `ESP_Telegram_BOT_2.3.ino`
2. Оберіть плату: **NodeMCU 1.0 (ESP-12E Module)**
3. Порт: ваш COM порт
4. **Sketch → Upload**

### **Крок 3: Перше налаштування**

#### **Варіант A: Через веб-інтерфейс (рекомендовано)**

1. При старті затисніть кнопку на 2-3 секунди (AP режим)
2. Підключіться до WiFi: `EDwIC_XXXX` (пароль: `qawsedrf`)
3. Відкрийте: `192.168.4.1/Seting.html`
4. Заповніть:
   - **WiFi name**: ваша WiFi мережа
   - **Password**: пароль WiFi
   - **пароль бота**: будь-яке число (напр. 12345)
   - **Telegram Bot Token**: токен вашого бота (див. нижче)
5. Натисніть **SAVE**
6. Перезавантажте пристрій

#### **Варіант B: Через Telegram**

1. Після перезавантаження підключіться до вашої WiFi мережі
2. Знайдіть свого бота в Telegram
3. Надішліть `/start`
4. Введіть пароль (за замовчуванням: 12345)
5. Отримайте доступ до меню

## 📱 Отримання токену Telegram бота

### **Крок 1: Створіть бота**

1. Відкрийте Telegram
2. Знайдіть **@BotFather**
3. Надішліть `/newbot`
4. Введіть ім'я бота (напр. `EDwIC Controller`)
5. Введіть username бота (має закінчуватися на `bot`, напр. `my_edwic_bot`)
6. Отримайте токен (виглядає як: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### **Крок 2: Збережіть токен**

1. Скопіюйте токен
2. Відкрийте веб-інтерфейс (`192.168.4.1/Seting.html`)
3. Вставте токен в поле **Telegram Bot Token**
4. Натисніть **SAVE**

### **Крок 3: Дізнайтеся Chat ID**

1. Відкрийте свого бота в Telegram
2. Надішліть будь-яке повідомлення
3. Відкрийте: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Знайдіть `"chat":{"id":123456789,...}`
5. Це ваш Chat ID (alluser)

## ⚙️ Конфігурація

### **Файл Config.json:**

```json
{
  "SID_STA": "MikroTik",
  "PAS_STA": "qawsedrf",
  "Start_status": 1,
  "share_sensor": 0,
  "alluser": 123456789,
  "Time_D": 28800,
  "Time_N": 75600,
  "TB_pasword": 12345,
  "TB_Token": "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz",
  "users": [123456789, 0, 0, 0, 0, 0, 0, 0, 0]
}
```

### **Змінні:**

| Змінна | Опис | Приклад |
|--------|------|---------|
| `SID_STA` | WiFi SSID | `"MikroTik"` |
| `PAS_STA` | WiFi пароль | `"qawsedrf"` |
| `TB_pasword` | Пароль для доступу до бота | `12345` |
| `TB_Token` | Токен Telegram бота | `"1234567890:ABC..."` |
| `alluser` | Головний користувач (Chat ID) | `123456789` |
| `users[]` | Список користувачів (до 9) | `[123, 456, ...]` |
| `Time_D` | Час денного профілю (секунди) | `28800` (8:00) |
| `Time_N` | Час нічного профілю (секунди) | `75600` (21:00) |

## 🔐 SSL/TLS оновлення

### **Що змінилося:**

**До версії 2.2:**
```cpp
// Потрібно оновлювати fingerprint раз на 6 місяців

```

**Версія 2.3:**
```cpp
// Автоматична перевірка сертифікатів

```

- ✅ Немає ручного оновлення fingerprint
- ✅ Telegram працює без обмежень

## 🐛 Вирішення проблем

### **Помилка компіляції:**
```
error: 'DynamicJsonDocument' was not declared in this scope
```
**Рішення:** Встановіть ArduinoJson **6.21.5** (НЕ 7.x!)

### **Telegram не підключається:**
```
Telegram connecting NOK
```
**Причини:**
- Неправильний токен бота
- Проблема з інтернетом
- Застарілий CTBot

**Рішення:**
1. Перевірте токен в налаштуваннях
2. Переконайтесь, що пристрій має доступ до інтернету
3. Оновіть CTBot до 2.1.14

### **Веб-інтерфейс не відкривається:**
1. Переконайтесь, що підключені до WiFi пристрою
2. Спробуйте `192.168.4.1` або локальну IP адресу
3. Очистіть кеш браузера

### **Конфігурація не зберігається:**
1. Перевірте Serial Monitor на помилки SPIFFS
2. Спробуйте форматувати SPIFFS:
   ```cpp
   SPIFFS.format();
   ```
3. Перезавантажте пристрій

## ✅ Перевірка після оновлення

1. **Telegram працює:**
   - Надішліть `/start` боту
   - Введіть пароль
   - Отримайте відповідь

2. **Токен зберігається:**
   - Відкрийте веб-інтерфейс
   - Перевірте поле "Telegram Bot Token"
   - Токен має бути збережений

3. **SSL стабільний:**
   - Пристрій працює більше 24 годин
   - Немає помилок підключення
