# ПРАВИЛА РОБОТИ З ПРОЄКТОМ

**КРИТИЧНО:** 
Ніколи не зберігати (не робити git push) весь код цього проєкту на GitHub!
Репозиторій на GitHub (`olegi4a/esp-telegram-settings`) призначений **ВИКЛЮЧНО** для хостингу файлу `index.html` (Telegram Mini App).

Для завантаження оновленого Mini App використовується спеціальний скрипт `update_github.ps1` (через GitHub REST API), а не стандартний `git push` всього репозиторію. 
Усі інші файли (C++ код, `Home.html`, налаштування PlatformIO) мають залишатися лише локально.
Файл `.gitignore` налаштований так, щоб ігнорувати все, окрім `index.html`.
